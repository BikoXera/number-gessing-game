# number-gessing-game
A fun and interactive number guessing game built to test your intuition! The computer picks a random number, and you try to find it in the fewest tries possible.
How to Play------ 
1) The program picks a random number between 1 and 200.
2) You enter your guess.
3) The game tells you if the secret number is higher or lower than your guess.
4) Keep guessing until you find the correct number.
